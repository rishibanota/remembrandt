## [Unreleased]

### Added
- Initial release: persistent, file-based memory store for coding agents.
- `remembrandt` CLI with `remember`, `recall`, `search`, `resume`, `status`,
  `edit`, `forget`, `export` and `reset` commands.
- `SKILL.md` skill definition for Claude Code / Cursor / Codex.
- Install scripts for macOS/Linux (bash) and Windows (PowerShell).
- Zero runtime dependencies (Python 3.9+ standard library only).
- Test suite (23 tests) covering store and CLI.
- `MEMORY.md` auto-compilation grouped by category.
